# 07 · 求星行自过滤

## 症状

插件详情页底部的 `⭐` 求星提示，出现在**别的插件**的详情页上；或者反过来，自己的页面没有。

## 根因

`plugins.detail.section` 是一个 **list slot**，宿主在**每一个**插件详情页上派发它 —— 组合包页、
行页、官方插件页都算。派发的 props 形如：

```js
{ subject: { kind: 'bundle'|'row', pkg: { name, version?, installed, enabled, rows }, row? } }
```

条目如果不看 `subject.pkg.name` 就渲染，会污染所有详情页。行页只有在某个插件注册了
`plugins.row.config` 时才存在，所以「没有行页」时也不能假设 props 形状。

## 证据

- `src/client/index.js` 的 `DetailStarLine`：`if (!pkg || pkg.name !== DETAIL_PACKAGE) return null`；
- 同一段注释记录了契约来源：0.2.2-rc.1 的 `@deepseek-ai/dsh-client-ui-plugin-manager` 与实时
  Slots 目录；
- 插件管理器 README（随 app.asar 分发）说明该 slot 的派发范围。

## 结论

- list slot 的条目必须**自过滤**，只认自己的 `subject.pkg.name`；
- **不要用 `plugins.row.config` 放求星行**：那个 keyed slot 会占用该行的配置页；本插件没有
  自建配置页，`prices` / `matchMap` 由仪表盘的定价弹窗写回，`currency` 是默认币种；
- 求星行只是一行文本：Unicode 星形、纯文本、不新增链接，颜色只用主题 token。
